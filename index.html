Link Opener

Open multiple URLs simultaneously in your preferred browser.

Download for Windows View on GitHub

Link Opener is a lightweight Windows desktop application built with C# WPF on .NET 8.0. It allows you to open multiple URLs at once using a text file list.

Chrome Firefox Edge Brave Helium

Features

Multi-Browser Support

Works with Chrome, Firefox, Edge, Brave, and Helium browsers

Private Mode

Option to open all links in incognito or private browsing mode

Drag & Drop

Drag your text file directly into the app interface

Persistent Settings

Saves your selected browser and configuration preferences

How to Use

01

Prepare Your Links

Create a text file with one URL per line:

https://github.com
https://stackoverflow.com
https://news.ycombinator.com
02

Launch Application

Run LinkOpener.exe from your installation folder

03

Load File

Select your text file or drag and drop it into the window

04

Open Links

Select your preferred browser and click Open

Requirements

  • Windows 10 or Windows 11 (64-bit)
  • .NET 8.0 Desktop Runtime
